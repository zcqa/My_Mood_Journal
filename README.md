# 我的情绪日记 (My Mood Journal)

## 项目简介

这是一个以隐私为先、零门槛的网页应用，帮助用户通过每日情绪签到，记录、观察并理解自己的情绪波动。

## 核心特性

- ✅ **隐私优先** - 所有数据纯本地存储（localStorage），不上传任何服务器
- ✅ **极简操作** - 简单直观的界面，一键记录心情
- ✅ **数据可视化** - 使用 Chart.js 展示情绪波动趋势
- ✅ **智能关怀** - 自动识别情绪模式，提供适时的建议
- ✅ **关键词分析** - 扫描笔记关键词，引导心理健康资源

## 功能列表

### 基础功能
1. 每日情绪记录（5种情绪选择：😄 🙂 😐 😟 😠）
2. 可选文字笔记
3. 本地数据存储
4. 历史记录查看
5. 情绪曲线图表

### 智能功能
6. 连续负面情绪检测（连续3天情绪低落时提醒）
7. 个性化建议
8. 笔记关键词分析（压力、孤独、焦虑、抑郁、失眠等）
9. 健康资源引导

## 如何使用

### 方法一：直接打开
1. 下载所有文件到同一目录
2. 双击 `index.html` 在浏览器中打开
3. 开始记录你的心情！

### 方法二：使用本地服务器（推荐）
```bash
# 如果安装了 Python
python -m http.server 8000

# 如果安装了 Node.js
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

所有数据都存储在您的浏览器本地存储中，不会上传到任何服务器。您可以随时通过浏览器开发者工具查看或清除这些数据。
